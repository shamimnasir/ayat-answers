# আল কোরআন (Ayat Answers)

A Vite + React + TypeScript Quran reader with Arabic text, Bangla pronunciation,
translations, search, and accessible reading controls.

## Local development

```sh
npm install
npm run dev
```

Useful checks:

```sh
npm run lint
npm test
npm run build
```

## Deployment

The application is a static Vite site. Run `npm run build` and publish the
generated `dist/` directory with the Git-based hosting provider used by the
project. The source repository is the single source of truth; no third-party
visual editor or injected branding is required at runtime.

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
